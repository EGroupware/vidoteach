Functions

Design lessons digitally

VIDOTEACH combines all the important functions for media-supported learning. Use any existing videos, add didactic value, interactive tips, comments and questions. Create exams based on videos or PDFs. Give teachers live feedback with one click or ask questions about content.

DATA PROTECTION

Data protection & data sovereignty

  • VIDOTEACH complies with current German data protection law.
  • All software is open source – open source code means security & sovereignty.
  • When used in the cloud, VIDOTEACH runs exclusively on servers in Germany.

Building blocks

VIDOTEACH building blocks

Independent learning with videos

VIDOTEACH makes self-directed learning easy. You add both text markers and visual signs at the right points in the video image and so create a tailor-made learning experience.

Reflection tool

The reflection tool makes it easy for learners to analyse video material independently in order to develop a deeper understanding.

Live feedback tool

During lectures or presentations, participants can easily give instant feedback without interrupting the learning experience, improving interaction with the presenter.

Tasks in the video

VIDOTEACH lets you insert tasks into videos to check understanding in a playful way and promote interactive learning.

Media-supported lectures

Teachers can easily add didactic value to existing videos to make lessons more interactive and easier to understand.

Exams and tests

VIDOTEACH makes preparing for exams as easy as possible. As a teacher, you can not only use relevant video content, but also easily create exams with questions and image markers. This makes targeted exam preparation and video-based exams even more effective and flexible.
